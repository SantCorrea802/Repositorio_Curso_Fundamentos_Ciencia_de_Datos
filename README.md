# Proyecto:

## Terremotos en el sur de Asia ¿En qué zonas hay más temblores y por qué?

Durante el desarrollo de este proyecto se hace un análisis de los datos brindados por [South Asia Earthquake Events Dataset (1904–2024)](https://www.kaggle.com/datasets/shahnawaj9/earthquakes-south-asia/data) que describen diferentes factores tomados de terremotos en la región del sur de Asia, el objetivo de este repositorio es dar a conocer los factores que influyen en que ocurran terremotos en ciertas zonas y de cierta magnitud, todo esto con lo aprendido en las clases del curso.
